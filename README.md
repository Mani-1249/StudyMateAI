## 📚 In-Repo User Guide (Quick Start)

### 1️⃣ Getting Started
* Open the deployed app: [StudyMateAI Live App](https://sgpai-study-buddy.streamlit.app/)
* Select a mode from the sidebar: **Explainer**, **Summarizer**, or **Quizzer**.
* Provide your input (topic, notes, PDF, or questions) in the main chat area.

### 2️⃣ Mode Usage
* **Explainer:** Type your concept or question (e.g., *"Explain paging in OS for exams"*). StudyMateAI returns a simple, exam-oriented explanation plus an idea for a quick sketchable diagram.
* **Summarizer:** Upload a PDF or paste notes to get an exam-ready summary with headings, bullets, and practice questions.
* **Quizzer:** 
  * *Generate Questions:* Get practice MCQs and short-answer questions complete with an answer key.
  * *Solve Questions:* Paste exam questions to receive concise, structured answers.
  * *Evaluate Answers:* Paste both questions and your answers to receive scoring and detailed feedback.

### 3️⃣ Tips for Best Results
* Include exam context (e.g., *"for B.Tech 3rd sem OS viva"*) for sharper responses.
* Use follow-up prompts within the same chat thread to refine explanations.
* Click **New Chat / Reset** in the sidebar before moving to a completely new topic.
